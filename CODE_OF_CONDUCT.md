# Contributor Covenant Code of Conduct — summary

This project follows the Contributor Covenant (v2.1, https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive; harassment, trolling, personal attacks, and publishing others' private information are unacceptable. Reports go to the maintainer via GitHub contact for this repository. Maintainers may remove comments, issues, or PRs that violate this code and may ban repeat offenders.
